# Security policy (pre-release)

Tiqnora Remote has no officially published binary or operational relay as of 2026-10-12. Do not trust third-party files claiming to be its installer.

Security reports: info@tiqnora.com — subject "Tiqnora Remote Security".

Normal remote-support sessions must require the informed approval of the device owner; unattended access must be opt-in, discoverable, time-bounded or revocable. Do not use the software for access without authorization.

No passwords, access tokens, server keys or personally identifying client data should be filed in public GitHub issues.
