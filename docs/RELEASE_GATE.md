# Release gate — do not publish binaries until all pass

- [ ] Dedicated Tiqnora-owned icon and application artwork, with no unintended upstream branding.
- [ ] Thorough source-level name, UI, Windows service, startup, deep-link and installer consistency checks.
- [ ] Correct AGPL-3.0 compliance, source publication, attributions and notices.
- [ ] Reproducible x64 Windows build with recorded exact dependencies and SHA-256 hashes.
- [ ] Malware/AV checks and independent security review; signed Windows installer when feasible.
- [ ] Tested owner-facing consent, clearly visible active connection, disconnect and revocation.
- [ ] Authentication, server identity verification, network abuse and rate-limiting validation.
- [ ] Tested on two real Windows machines, including firewall, NAT, unstable networks and file transfer.
- [ ] Public privacy, support, abuse and update policies.
- [ ] Licensed, stable, monitored server for ID/relay before public launch.
- [ ] Real EXE/MSI URLs only after approval; no non-working or misleading download link.

There is no functioning Tiqnora Remote installer at this stage.
